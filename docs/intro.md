# 项目简介

## 定位

sapic v2 与 v1 最大的区别是**前后端分离**与**数据落库**：

| | v1（已归档） | v2（当前） |
| --- | --- | --- |
| 后端 | Flask + 模板渲染 | Flask，只输出 JSON（`/api/v2`） |
| 存储 | Redis 为主存储 | Peewee + PostgreSQL / MySQL / SQLite |
| 前端 | layui + Jinja2 | Vue 3 + Vite + Element Plus（`web/`） |
| 插件 | 钩子，模板片段描述界面 | 钩子，**声明式 JSON 节点树**描述界面 |
| 客户端 | `/api/upload` | 统一 `/api/v2/upload`，客户端用 PAT 鉴权（配置见[快捷上传](usage.md)） |

版本号见 `server/sapic/version.py` 的 `__version__`，后台侧栏也会显示当前版本与是否有更新。

## 已提供的能力

- **上传**：表单文件、远程 URL（服务端抓取，含私网地址拦截）、拖拽与粘贴、批量队列；
  后缀白名单与按媒体类型（图片 / 视频）区分的大小上限。
- **图片管理**：列表（游标或页码分页，页码模式默认每页 15 并支持 ←/→ 翻页）、关键词与标签筛选、
  单张详情、单张删除与批量操作、标题 / 相册 / 可见性 / 标签 / 广场发布开关、复制分享模板
  （URL / HTML / Markdown / rST / 文件名 / 相册）；管理员可一键切到「全站」视图（仅公开图片）。
- **相册**：相册是独立实体（名称 / 描述 / 封面），可见性按相册（public / private / shared），
  单张图片可覆盖；支持按用户名分享成员并授予 read / write 权限与有效期。
- **账号**：本地注册（禁用词、密码强度）、注册审核（含拒绝理由与通知邮件）、邮箱验证、
  找回密码、头像裁剪、个人偏好、多枚 PAT（`read` / `upload` / `write` / `admin` 四档 scope）、
  会话吊销、自助注销。
- **存储**：多后端 + 优先级 + 多副本（主后端同步、其余异步），后台可增删改与单独配置；
  用户自定义存储（`/api/v2/me/backends`，站点开关 `allow_user_backends`）。
- **扩展**：内置本地 / 七牛 / 又拍云 / GitHub / Gitee 驱动、WebP 后处理、Passport OIDC 登录；
  第三方包通过钩子体系接入，后台可安装、启停、配置。
- **广场**：可选（默认关闭）的公开曝光渠道，与权限无关，只有主动发布的公开图片会进入。

## 不打算做的

- 个人 RSS（`/feed`）：匿名聚合出口会泄露「某用户有哪些图、何时上传」。
- `sendmail` 钩子、`token` 钩子、`/api/extendpoint`：分别被内置 SMTP、PAT、声明式动作取代。
- v1 的 `/api/upload` 兼容层：维护双份上传语义的成本高于让客户端改一次配置，
  PicGo / uPic / Typora 等按[快捷上传](usage.md) 指向 `/api/v2/upload` 即可。
- 前端多语言（界面固定中文，后端消息固定英文、由前端映射）。

完整的 v1 → v2 功能对照与缺口清单见仓库根的 `MIGRATION.md`，架构细节见 `ARCH.md`。
